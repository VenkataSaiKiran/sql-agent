About this assistant

Overview

What's This Assistant?

Turns plain-English questions into safe, read-only SQL — and explains the answer back in plain English. It dynamically translates your questions into SQL SELECT queries, executes them safely against connected SQLite database schemas, and synthesizes results into executive summaries and interactive data tables.

Technology & Process

How Text-to-SQL Translation Works

  1. Your natural language question is combined with schema definitions (Customer, Product, "Order").
  2. The LLM constructs a candidate read-only SQLite SELECT query.
  3. An independent AST parser (sqlglot) validates statement safety, prevents data modification (DML/DDL), and appends safety limits.
  4. SQLite executes the safe query and returns structured row results.
  5. The LLM synthesizes an executive summary while the UI renders a scrollable data table.
NOTE: This assistant executes read-only SELECT queries strictly against connected database tables. If a question is out of scope or asks to modify data, it safely refuses to execute.
